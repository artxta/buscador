# BuscaCentro

Buscador de centros de Formación Profesional en España.

## ¿Qué hace?

Permite buscar centros de FP por familia profesional, nivel de estudios, enseñanza concreta y modalidad (diurno, nocturno, distancia, semipresencial). Los datos se cargan localmente desde archivos JSON para evitar dependencias de APIs externas.

### Funcionalidades

- **Búsqueda por cascada**: selecciona una familia profesional, luego el nivel, la enseñanza y la modalidad.
- **Ordenación por proximidad**: introduce tu ciudad para calcular distancias a los centros y obtener rutas con Google Maps.
- **Filtros**: por provincia y naturaleza (público/privado).
- **Test vocacional**: un cuestionario de 38 preguntas que recomienda familias profesionales según tus intereses y habilidades. Incluye casos especiales para quien no le gusta nada y para quien le gusta todo.
- **Detalle de centros**: enlace directo a la ficha oficial de cada centro en educacion.gob.es.

## Tecnologías

HTML, CSS y JavaScript puro. Sin frameworks ni dependencias.
